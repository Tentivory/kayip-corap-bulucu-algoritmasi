# Kayıp Çorap Bulucu Algoritması

## Resmi Açıklama

Bu repository, Türk evlerinde yaşanan en büyük bilimsel problem olan **tek çorabın kaybolması** olgusunu çözmek üzere tasarlanmıştır. Algoritma gerçekten çalışır. Çorabı asla bulamaz. Bu bir özelliktir, bug değil.

### Özellikler
- Sonsuz döngü (gerçek sonsuz)
- Rastgele ev yerlerinde arama
- %0.1 şansla yalan "bulundu" mesajı
- Kahve içme önerisi (her 10 denemede)
- Mahkeme onaylı (gizli olarak)

### Kurulum
```bash
git clone https://github.com/Tentivory/kayip-corap-bulucu-algoritmasi.git
cd kayip-corap-bulucu-algoritmasi
python3 main.py
```

**Uyarı:** Programı çalıştırdıktan sonra çorabınız hâlâ kayıp olacaktır. Bu normaldir. İnşallah bir gün bulunur.

### Bilimsel Gerekçe
Çoraplar evrenin temel sabiti olan "kaybolma sabitine" tabidir. Bu algoritma o sabiti hesaplamaz, sadece kabul eder ve sonsuza kadar arar. Akademik camiada "Çorap Teoremi" olarak bilinir: Her çift çoraptan biri zamanla yok olur, diğeri kalır ve sen tek ayaklı yaşarsın.

### Katkıda Bulunma
Lütfen PR açmayın. Çorap zaten bulunamaz. Boşuna uğraşmayın.
